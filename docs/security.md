# 权限与资源预算

## 工具授权

Agent 只执行当前注册表中的工具。工具参数经模式校验后调用。需要人工确认的工具可在注册时设置 `requires_approval=True`，执行时由可信入口在操作者明确确认后传入批准。模型生成的字段无法授权。项目提供计算、限定目录读取和可选搜索，没有终端执行工具。

本地文件只能从调用方授权的根目录读取。程序在打开文件后检查句柄对应的文件身份与范围，拒绝路径越界、普通文件之外的对象和多重硬链接。数字 PDF 用已检查的字节解析。使用受信任的本机目录，避免在任务执行时由其他进程改写源目录。

## 外部资料

工具结果作为资料传回模型。规划、证据分析和结论复查使用结构化输出，分析阶段拒绝工具请求。外部资料中的文字进入资料字段，不能授予文件或网络访问权限。联网研究需要操作者明确启用，仅访问维基百科的固定接口，拒绝重定向。模型过滤和引用检查仍有限，报告保留缺口供人工核对。

## 默认预算

| 范围 | 限制 |
|---|---|
| Agent Loop | 6 次模型调用、12 个工具请求、120 秒、单次请求消息与工具定义共 20000 字符、累计已报告的 16384 Token |
| 单次工具结果 | 6144 字符，超限时向模型返回明确错误 |
| 研究分析 | 180 秒、累计已报告的 24576 Token、每个子任务最多 2 次尝试 |
| Ollama 响应 | 普通响应和每个流式帧最大 512 KiB，嵌入批次响应最大 4 MiB |

Token 总量由服务在响应后报告。达到预算停止后续调用。模型请求收到剩余时间，外部读取另有独立网络时限。已经开始的同步工具或解析器按自身执行时限返回。重试、超限和未知工具都有可观察结果。
